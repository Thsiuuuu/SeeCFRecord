# SeeCFRecord
输入用户的 cfId，可以查看一个用户在 $[800,1100]\,[1200,1600]\,[1700,2100]\,[2200,\infty)$ 分数段的已经通过的题。


**2026年1月11日 00:37新增更新**

**新增功能：** 在网页下端添加了各分段的柱状图，更为直观。
